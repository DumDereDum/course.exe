# Источник сохранённого отчёта SAST

Изолированный пример для иллюстрации трассы и карточки находки на слайдах 06 и 08. Функция освобождает указатель, затем повторяет освобождение при retry != 0. Пример используется для объяснения отчёта, а не как готовое задание мини-практики.

Команда из этой папки:

```sh
clang --analyze -Xanalyzer -analyzer-output=text ownership.c
```

Версия сохранённого запуска: Apple clang version 16.0.0 (clang-1600.0.26.6).

Отчёт: `assets/examples/security/sast/report.txt` от корня репозитория. Никакие зависимости не устанавливались. Исполняемый файл не запускался: это статический анализ.
