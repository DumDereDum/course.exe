Ещё один приём · multi-stage

Итоговый образ получает артефакт через COPY --from=build, без компилятора.

Сценарий: первые четыре кадра — первая сборка строка за строкой. Пятый — повторная сборка после изменения app.py.

Сказать: кеш учитывает инструкцию и её входы. Пока requirements.txt не менялся, его COPY и RUN с pip повторно используют результат. Если код скопировать до RUN, изменение кода заставит переустановить пакеты.

Граница: изменение requirements.txt пересоберёт этот COPY, RUN и следующие шаги. Multi-stage оставляет инструменты сборки в первом этапе и копирует в итоговый образ нужный артефакт.
