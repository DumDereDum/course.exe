DOCKER / 14 · проверка работы

Проверяем процесс, логи и ответ

ВМ demo · сохранённый пример
$ docker compose ps --all
Норма · сокращённый вывод
NAME             STATUS
demo-web-1       Up 2 minutes
demo-backend-1   Up 2 minutes
ВМ demo · сохранённый пример
$ curl -i http://localhost/api/health
Норма · ответ приложения
HTTP/1.1 200 OK
{"status":"ok"}
ВМ demo · сохранённый пример
$ docker compose ps --all
Сбой · сокращённый вывод
NAME             STATUS
demo-web-1       Up 2 minutes
demo-backend-1   Exited (1)
ВМ demo · сохранённый пример
$ docker compose logs --tail=20 backend
Сбой · фрагмент лога
backend-1 | ...
backend-1 | SyntaxError: invalid syntax
ВМ demo · сохранённый пример
$ docker compose stats --no-stream
Медленно · сокращённый вывод
NAME             CPU %   MEM
demo-web-1        0.2%   12MiB
demo-backend-1     95%   480MiB

ps --all → logs → HTTP-запрос; при торможении — stats.

Сценарий: кадры 1–2 — исправная работа; 3–4 — намеренно сломанный backend; 5 — отдельная ситуация медленного ответа. Все выводы сокращены и подготовлены, это не запущенный стенд. Пробел — дальше, Shift + пробел — назад, R — сброс.

Сказать: ps --all показывает и остановленные контейнеры. Статус Up означает, что главный процесс работает; без healthcheck он не подтверждает готовность API. Сначала ищем отсутствующий или завершившийся сервис, затем читаем его logs. После исправления отправляем HTTP-запрос через web к API. stats --no-stream показывает один снимок CPU и памяти только работающих контейнеров; высокая загрузка — повод разбираться дальше, не готовый диагноз.

Граница: /api/health и ответ 200 требуют реализации маршрута и прокси в web. SyntaxError моделирует ошибку в учебном app.py; вывод не получен из реального backend. После исправления кода образ надо пересобрать. Числа stats иллюстративные и не являются порогами нормы.

Спросить: достаточно ли двух строк Up, чтобы объявить приложение исправным? Ответ: нет, нужен запрос к приложению; если настроен healthcheck, можно отдельно смотреть и его состояние.

Источники: ps; logs; stats.
