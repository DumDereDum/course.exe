RUN исполняется при сборке; CMD — при запуске контейнера.

Сценарий: один кадр на одну инструкцию. Перед RUN спросить, когда работает pip; перед CMD — запустилось ли приложение.

Сказать: docker build читает Dockerfile и контекст. FROM выбирает основу, COPY переносит файлы, RUN сохраняет результат команды. CMD сохраняет команду в конфигурации образа; процесс появится после docker run.

Граница: site-packages — условное обозначение; реальный путь зависит от образа. Справа — состояние будущего контейнера, не работающий процесс.

Источники: Dockerfile; контекст сборки.
