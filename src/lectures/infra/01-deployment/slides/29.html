СЕТЬ / 04 · Docker

Снаружи виден web.
Внутри web находит backend.

Сказать: Docker Engine работает в ВМ demo, поэтому порт 80 опубликован на ВМ, а не непосредственно на KVM-хосте. Docker направляет входящий запрос к web:80. Web как прокси обращается к backend:8000 по имени сервиса через сеть Compose. Backend не имеет ports, поэтому внешний клиент не обращается к нему напрямую. Сама сеть не настраивает прокси: конфигурация web должна явно указывать backend:8000.

Спросить: какой адрес web использует для backend и нужен ли backend опубликованный порт? Ответ: backend:8000; публикация не нужна, потому что оба сервиса в одной сети Compose.

Граница: внешний путь от KVM-хоста до ВМ и проброс 8080 → 80 разбираются позже. Здесь показана сеть Docker внутри ВМ. Готового web/backend в стенде пока нет.

Источники: сеть Compose; публикация порта.
