ANSIBLE / 01 · подготовка хоста

Ansible готовит
Linux-хост для ВМ.

create-vm.yml · KVM-хост
- name: Пакеты для KVM
  ansible.builtin.apt:
    name:
      - qemu-kvm
      - libvirt-daemon-system
      - virtinst
    state: present
    update_cache: true
На Linux-хосте · demo: 2 vCPU, 2 ГБ
Ansible
   ├─ apt → QEMU + libvirt
   └─ get_url → cloud image
                   │
                   ▼
                demo.img

В образе уже установлена Ubuntu.

Сказать: пример рассчитан на Ubuntu-хост с доступным KVM, который проверяли ранее. Для простоты Ansible запускается на этом же хосте: inventory содержит группу kvm_host и строку localhost ansible_connection=local. Команда запуска — ansible-playbook -i inventory.ini create-vm.yml. В play с hosts: kvm_host и become: true задача apt устанавливает пакеты на экране. Следующие задачи получают готовый cloud image Ubuntu и создают из него отдельный диск demo.img, сохраняя существующий диск при повторном запуске. Для модуля создания ВМ дополнительно нужны коллекция community.libvirt, привязки Python к libvirt и lxml. На экране показан фрагмент playbook, а не готовый стенд.

Спросить: где выполняется задача apt? Ответ: на Linux-хосте с KVM, ещё до запуска гостевой Ubuntu.

Источники: пакеты libvirt в Ubuntu; cloud image и libvirt.
