ANSIBLE / 03 · настройка гостя

После запуска Ansible
входит в Ubuntu по SSH.

configure-vm.yml · гостевая ОС
- hosts: demo
  become: true
  tasks:
    - name: Установить Nginx
      ansible.builtin.apt:
        name: nginx
        state: present
Новый адресат
Ansible
   │ SSH
   ▼
Ubuntu в demo
   │ apt
   ▼
Nginx

inventory.ini: demo ansible_host=192.168.122.100 ansible_user=ubuntu. IP здесь — пример. Повторный запуск не ставит Nginx заново.

Сказать: после запуска ВМ узнаём её фактический IP-адрес в сети libvirt и записываем его в inventory; 192.168.122.100 на экране — только пример, DHCP может выдать другой адрес. Команда ansible-playbook -i inventory.ini configure-vm.yml запускает второй playbook. Ansible подключается к гостевой Ubuntu по SSH с ключом, переданным через cloud-init, и выполняет задачу apt уже внутри гостя. become: true даёт права для установки пакета. state: present описывает требуемое состояние: если Nginx уже установлен, повторный запуск не устанавливает его заново. Это подготовленный пример, реальный адрес и доступность SSH должны быть проверены на стенде.

Спросить: на каком компьютере установится Nginx? Ответ: в гостевой Ubuntu внутри ВМ demo, потому что play обращается к хосту demo из inventory.
