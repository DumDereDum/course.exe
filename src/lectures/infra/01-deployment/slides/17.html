Образ общий; запись каждого контейнера хранится отдельно.

Сценарий: каждый кадр — одна подсвеченная строка и одно изменение справа. Пробел — дальше, Shift + пробел — назад, R — сброс.

Сказать: COPY переносит файлы, RUN выполняется при сборке. Схема показывает логические изменения; реальное число слоёв зависит от сборщика. docker run добавляет слой записи поверх неизменного образа.

Граница: последняя строка — команда терминала. Образ backend:v1 предварительно собирают с этим тегом. Второй контейнер получит свой слой записи.
