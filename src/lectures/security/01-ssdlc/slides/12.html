12 / практика SAST · разбор

Разбор исправления

До исправления · фрагмент task.c
if (retry) {
    puts("retry scheduled");
    free(task);
}
free(task);

TP · CWE-415 · два освобождения одного ресурса.

После исправления · фрагмент task.c
if (retry) {
    puts("retry scheduled");
}
free(task);

Поведение retry сохранено; дублирующее free удалено.

Сохранённая проверка · Clang 16
$ clang --analyze task.c \
  -Xanalyzer -analyzer-output=text \
  2> reports/sast.txt
$ sh check.sh
OK: обычный режим и retry работают

Исправление проверено анализом и запуском обоих режимов.

Сказать: отмеченная анализатором операция free после условной ветки действительно повторяет освобождение при retry != 0. Причина находится также в ветке выше. Находка подтверждена как TP, класс слабости — CWE-415 Double Free.

Исправление: удалено освобождение из условной ветки, оставлено общее освобождение. Сообщение retry scheduled и обработка обычного режима сохранены. Вариант отключения режима retry или подавления unix.Malloc не соответствует заданию.

Проверка: исходный и исправленный варианты проанализированы Apple clang 16.0.0 на macOS arm64. Clang запускался напрямую командой с экрана, без оболочки analyze.sh. После успешного повторного анализа reports/sast.txt пуст. check.sh собрал только исправленную программу и проверил вывод двух режимов. Исходный вариант с дефектом не запускался.

Материалы: assets/examples/security/sast-lab/before.txt, after.txt, verification.txt и task.fixed.c. Это результаты отдельного сохранённого запуска, а не выполнение команд в браузере. Рецепт Ubuntu-образа включён в архив; контейнер не проверен, поскольку Docker daemon на машине подготовки не запущен.

Граница: исчезновение этой находки подтверждает результат выбранной проверки. Два запуска проверяют сохранение конкретного поведения, но не доказывают полную безопасность программы.

Показ: три кадра: причина, изменение, свидетельства проверки. Пробел — дальше; Shift + пробел — назад; R — сброс. После последнего кадра последовательность останавливается. Время: 2 минуты.
