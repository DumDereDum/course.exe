Кадр 1: для одного случая есть CVE, идентификатор БДУ и бюллетень производителя. Соответствие CVE-2022-37434 / BDU:2022-05325 проверено по официальному бюллетеню РЕД ОС ROS-20221207-01 от 07.12.2022. Прямой сайт БДУ при подготовке недоступен; не заявлять, что его карточка была прочитана. Локальный резерв сведений — assets/examples/security/sca/sources.md.

Кадр 2: upstream исправление опубликовано в zlib 1.2.13. Производитель РЕД ОС 7.3 указывает обновление zlib-0:1.2.11-15.el7.x86_64. Поэтому базовой строки 1.2.11 недостаточно для оценки дистрибутивного пакета: нужны epoch, версия, release и advisory соответствующей платформы. Подробности состава backport в этом блоке не разбираются.

Разбор: Trivy выбирает источники advisory по типу и происхождению пакета. В нашем примере Conan используется GitLab Advisory Database Community. Для пакетов ОС нужны сведения её поставщика. Их диапазоны нельзя автоматически переносить на upstream или другую ОС. Trivy в этом запуске не запрашивал БДУ; соответствие добавлено отдельно по источнику.

Граница: CWE описывает класс слабости, CVSS — её техническую тяжесть; они не заменяют идентификацию пакета и проверку применимости. 1.2.13 здесь — историческое исправление выбранной CVE, не рекомендация версии для нового проекта.
