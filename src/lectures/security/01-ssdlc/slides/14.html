Прямая команда · пример сборки ASan
clang -O1 -g \
  -fsanitize=address \
  -fno-omit-frame-pointer \
  task.c -o task-asan

ASan замечает ошибку.
AFL++ подбирает вход, который к ней приводит.

Кадр 1: одна версия исходников может дать несколько сборок. Инструментация ASan добавляет проверки памяти и библиотеку исполнения. Инструментация AFL++ передаёт данные о покрытии. Это разные задачи; их можно объединить. Проверять выпускную конфигурацию также необходимо.

Кадр 2: показать прямую команду без запуска преподавателем. -fsanitize=address нужен при компиляции и линковке; Clang в этой команде делает оба шага. -g даёт отладочную информацию, -fno-omit-frame-pointer сохраняет указатель кадра для удобной трассы. Для перевода адресов в строки нужна символизация.

Связь с практикой: для AFL++ будем использовать afl-clang-fast; AFL_USE_ASAN=1 включает ASan при сборке. Команда и подготовка окружения появятся в блоке 5. Существующий образ SAST ещё нужно дополнить AFL++ и runtime ASan: его пригодность для фаззинга не заявлена.

Граница: ASan выявляет, например, выход за границы, use-after-free и double-free на выполненных путях. UBSan проверяет выбранные виды неопределённого поведения, TSan — гонки; они не включаются одним только -fsanitize=address. Подробности оставлены устному пояснению. ASan runtime предназначен для тестирования.
