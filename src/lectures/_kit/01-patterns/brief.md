# Мастерская формата

Служебная коллекция для преподавателя. Показывает готовые приёмы, не учит отдельной дисциплине.
01 — титул; 02 — две колонки + вывод; 03 — управляемая схема; 04 — внешняя ссылка с резервным примером;
05 — SVG из отдельного файла; 06 — интерактив внутри iframe по кнопке; 07 — карта из карточек.
08 — интерактивная карта регистров и запись в их части (register-map.html).
09 — лаборатория подготовленных команд и состояний (command-lab.html).
10 — интерактивная карта системных вызовов Linux x86-64 (syscall-explorer.html).
11 — ограниченная модель WHILE: счётчик, флаги, возврат и байты (while-loop.html).
Регистры и порядок байтов показаны в asm/01-isa; шаблоны registers.html и endian.html.
При расширении библиотеки добавлять только образцы, которые реально поддерживает движок.
