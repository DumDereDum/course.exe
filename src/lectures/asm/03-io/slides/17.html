03 / ввод, вывод и числа

Считаем цифры
и повторяем деление.

inc ecx

Увеличить число записанных цифр: после первой записи ECX = 1.

Байты команды: FF C1.

test eax, eax

Проверить, стало ли частное нулём. EAX не меняется; при нуле ZF = 1.

Байты команды: 85 C0.

jnz digits

Если ZF = 0, цифры ещё остались: вернуться к xor edx, edx.

Байты команды: 75 + 1 байт смещения до метки.

Проверка стоит после тела: даже число 0 даст одну цифру '0'.

Сказать: После первого DIV для 42 в EAX остаётся 4: TEST даёт ZF=0, продолжаем. После второго DIV в EAX=0: ZF=1, JNZ не выполняется. Это цикл с проверкой после тела. Для исходного нуля тело всё равно один раз запишет символ 0; иначе получилась бы пустая строка. TEST выполняет AND для флагов, не записывая результат. Его смысл здесь — проверка на ноль.

Спросить: Сколько раз тело выполнится, если результат равен нулю? Ответ: Один раз: получим цифру 0, затем завершим цикл.
