02 / сумма от 1 до N

Счётчик выбирает число.
Накопитель хранит сумму.

Первое слагаемое — 1 · ECX заранее равен 0

Мысль: EAX хранит очередное слагаемое i, EBX — N, ECX — сумму. ECX подготовлен со значением 0 до этого фрагмента. До MOV EAX неизвестен; MOV устанавливает 1. Целые signed32, демонстрация ограничена N=0…5.

Показ: N=4. После первого ADD EAX ещё 1, ECX уже 1; INC меняет только счётчик на 2. Истории EAX: 1→2→3→4→5; ECX: 0→1→3→6→10. Первая итерация подробно, остальные быстрее. Итог EAX=5, ECX=10, четыре завершённые итерации.

Граница: C продолжает при i≤N, поэтому выход JG при i>N, то есть ZF=0 и SF=OF. При i=N ZF=1, последнее слагаемое входит в сумму. Если поставить JGE, число N будет пропущено; для N=4 получится 6 вместо 10. Для N=0 сумма остаётся 0, EAX=1, тело не выполняется.

Флаги: ADD и INC меняют ZF/SF/OF, JMP сохраняет. CMP заново выставляет их для JG. При равенстве особенно выделить ZF=1. В выбранном диапазоне нет переполнения. Подпись показывает источник флагов.

Байты: B8 01 00 00 00; 39 D8; 7F 06; 01 C1; FF C0; EB F6. F6 — signed8 −10: 40100F−10=401005. Каждая пара hex-цифр имеет описание HEX/BIN. Метки не занимают байтов.

Управление: пробел — инструкция, Shift + пробел — назад, R — начало с выбранным N. На done остановка. Истории и число итераций — пояснения, не регистры. Около 7 минут. Далее — три типовые ошибки.
