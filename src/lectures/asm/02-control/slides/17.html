02 / разбор · for

for: инициализация один раз.

1 · На C
value = 0;
for (i = 0; i < limit; i++) {
    value += 2;
}

EAX = i · EBX = limit · ECX = value = 0 заранее

2 · На NASM
mov eax, 0
check: cmp eax, ebx
jge done
add ecx, 2
inc eax
jmp check
done:

jge выходит при i ≥ limit. Возврат на check минует MOV; тело ADD стоит перед INC.

Пройти три блока: EAX = i, EBX = limit, ECX = value. Порядок в теле: сначала работа (add ecx, 2), затем изменение счётчика (inc eax), затем возврат к проверке.

Спросить: почему mov eax, 0 нельзя ставить после метки check? Ответ: jmp check вернулся бы на mov, при положительной границе счётчик снова стал бы нулём — цикл не завершился бы. При limit=0 выход остаётся немедленным.

Спросить: при limit = 0 что выполнится? Ответ: mov и проверка; тело и inc пропущены — инициализация выполняется всегда.
