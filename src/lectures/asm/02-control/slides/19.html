02 / разбор · сумма 1…N

Сумма 1…N: включаем границу.

1 · На C
sum = 0;
for (i = 1; i <= N; i++) {
    sum += i;
}

EAX = i · EBX = N · ECX = sum = 0 заранее

2 · На NASM
mov eax, 1
check: cmp eax, ebx
jg done
add ecx, eax
inc eax
jmp check
done:

jg done: i > N → выход. При i = N: ZF = 1, переход пропущен — последнее слагаемое входит в сумму.

Пройти три блока: EAX = i (очередное слагаемое), EBX = N, ECX = sum. Отличия от слайда 17: начало с 1, граница ≤ вместо < и прибавление текущего i вместо константы 2. ECX=0 подготовлен до показанного машинного фрагмента; эта загрузка есть в полной программе. Здесь N=0…5, переполнения счётчика и суммы нет; результат EAX=N+1 относится к этим границам.

Спросить: что даст замена jg на jge при N = 4? Ответ: 6 вместо 10 — сравнение при i = 4 даст ZF = 1, и переход выйдет, не добавив последнее слагаемое.

Спросить: где лежит результат после цикла? Ответ: в ECX; EAX к этому моменту равен N + 1 — первому числу за границей.

Далее: слайд 20 проходит сумму пошагово с историями EAX и ECX, выделением ZF = 1 при i = N и байтами B8…, 39 D8, 7F 06, 01 C1, FF C0, EB F6.
