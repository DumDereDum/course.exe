Как читать программу в Hex Editor

На компьютере · VS Code
examples/asm/build/abs
ПКМ → Open With… → Hex Editor

Открываем собранный файл abs. Исходный текст находится в abs.asm.

В палитре команд: Reopen Editor With… → Hex Editor.

Перейти к коду в этом примере
Hex Editor: Go To Offset
0x1000

Палитра: Windows — Ctrl + Shift + P, macOS — Cmd + Shift + P.

Код .text начинается с 0x1000 в показанном файле. Другой ELF может иметь другое смещение.

Показ: четыре подготовленных шага, затем повторить в настоящем VS Code. Пробел — вперёд, Shift + пробел — назад, R — сброс. Слайд показывает схему расширения; команды здесь не запускаются. Байты при наведении и фокусе имеют подписи HEX/BIN.

Открытие: вручную собрать abs по предыдущему слайду, заменив sum на abs. Открыть examples/asm/build/abs; внутри Docker это /work/build/abs. ELF содержит также заголовки, выравнивание и служебные данные. Смещение .text зависит от компоновки: readelf -S build/abs, колонка Off. Address — адрес в памяти; в Hex Editor показано положение в файле, а не RIP.

Чтение: каждая пара hex-цифр — один байт, строка — 16 байт. Смещение строки плюс номер колонки даёт положение байта. 0x1000 + 0x08 = 0x1008. Decoded Text — символы, не дизассемблер. Подготовленные байты взяты из файла abs на скриншоте автора; весь код занимает 0x15 = 21 байт. Нули после 0x1014 находятся вне показанного кода .text.

Дизассемблер: внутри Linux вызвать objdump -d -M intel build/abs. Его адреса — адреса в памяти; сопоставлять байты с Hex Editor через Off и Address секции .text. B8 в этой 64-битной программе без префиксов задаёт MOV EAX, imm32. 7D 02 — JGE на два байта вперёд от конца перехода, к 0x100C. MOV EAX,60 начинается в колонке 0E и продолжается на следующей строке.

Инспектор: выбрать F9, первый байт числа, а не B8. Четыре байта F9 FF FF FF в little-endian дают 0xFFFFFFF9: Int32 = −7, Uint32 = 4294967289. В настройках hexeditor.defaultEndianness выбрать little; скрытую панель можно вернуть через hexeditor.inspectorType = aside. Размер Int32 — четыре байта; просмотр не меняет файл. Дополнительный маршрут: objcopy -O binary -j .text build/abs build/abs.text.bin; открыть examples/asm/build/abs.text.bin — только 21 байт кода, начиная с нуля.
