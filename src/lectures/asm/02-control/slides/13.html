02 / разбор · if и else

Максимум: выбираем одну ветку.

1 · На C
if (a >= b) {
    result = a;
} else {
    result = b;
}

EAX = a · EBX = b · ECX = result · signed32

2 · На NASM
cmp eax, ebx
jl use_b
mov ecx, eax
jmp done
use_b: mov ecx, ebx
done:

jl use_b: a < b → ветка else. Иначе берём a; jmp done пропускает запись b.

Пройти три блока: EAX = a, EBX = b, ECX = result. Сравнение знаковое, поэтому jl, а не jb.

Спросить: что будет, если убрать jmp done? Ответ: после выбора a выполнение дойдёт до mov ecx, ebx и перезапишет результат — ECX всегда получит b.

Спросить: почему переход проверяет a < b, а не a ≥ b? Ответ: в выбранной компоновке else стоит дальше по адресам, поэтому JL ведёт именно в неё. Можно расположить ветки наоборот и использовать JGE. Это один вариант перевода if/else, а не обязательная форма.

Далее: слайд 14 выполняет этот фрагмент с выбором чисел: 7/3, 3/7, 7/7 и −3/−7, с байтами 39 D8, 7C 04, 89 C1, EB 02, 89 D9.
