02 / while

Цикл возвращает выполнение к проверке.

0…5 · один шаг — одна инструкция

Перед каждой итерацией снова проверяем условие.

Мысль: WHILE состоит из проверки, выхода при ложном условии, тела и возврата к проверке. Начальные EAX/EBX уже подготовлены; показанный код их не инициализирует. i — EAX, limit — EBX. Числа — signed32, для короткой демонстрации ограничены 0…5.

Показ: 0/3: CMP → JGE пропущена → INC → JMP check. Повторить для 1 и 2. При EAX=3 CMP и JGE приводят на done. Итог 3 итерации, EAX=3, EBX=3. История EAX показывает 0→1→2→3. Каждый шаг — одна инструкция; полного оборота цикла одной кнопкой нет.

Граница: 3/3 — тело не выполняется, ноль итераций. Также 4/3 — сразу выход, EAX остаётся 4. В C условие продолжения i<limit, в ассемблере JGE проверяет противоположное условие выхода i≥limit, то есть SF=OF.

Флаги: CMP выставляет SF/OF по вычитанию и сохраняет EAX/EBX. INC меняет EAX, а также SF/OF и другие флаги, кроме CF. В диапазоне 0…5 после INC SF=OF=0. JMP сохраняет флаги; следующий CMP заново готовит их для JGE. Подпись у флагов показывает последнюю изменившую их инструкцию. Подсветка SF/OF включается перед JGE.

Байты: 39 D8, 7D 04, FF C0, EB F8. Адреса 401000,002,004,006,008. F8 — signed8 −8, а не положительное смещение 248; 401008−8=401000. Метки не имеют байтов. Подсказки HEX/BIN у каждого байта.

Управление: пробел — шаг, Shift + пробел — назад, R — начало с текущими числами. Изменение поля сбрасывает показ. До CMP флаги неизвестны. Счётчик итераций и история — пояснения демонстрации, не машинные регистры. На done остановка; это фиксированная модель, не эмулятор. Время: 6–7 минут.

Источник: Intel SDM, Volume 2, INC и Jcc: https://cdrdv2-public.intel.com/782156/325383-sdm-vol-2abcd.pdf.
