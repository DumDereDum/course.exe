02 / разбор · je и jne

Равенство: переход по ZF.

1 · На C
if (a == b) {
    result = 1;
} else {
    result = 0;
}

EAX = a · EBX = b · ECX = result

2 · На NASM
cmp eax, ebx
je yes
mov ecx, 0
jmp done
yes: mov ecx, 1
done:

je yes: ZF = 1 → result = 1. Иначе result = 0; jmp done обходит вторую ветку.

Пройти три блока слева направо: сначала смысл на C, затем те же шаги инструкциями, затем условие перехода. EAX = a, EBX = b, ECX = result.

Спросить: зачем после mov ecx, 0 стоит jmp done? Ответ: иначе выполнение дойдёт до mov ecx, 1 и перезапишет результат — обе ветки сольются.

Спросить: je «помнит» сравнение? Ответ: нет, читает текущий ZF; если между cmp и je выполнить inc, ZF уже будет другим.

Далее: слайд 07 проходит этот же фрагмент пошагово с выбором чисел и байтами 74/75. jne — та же схема с байтом 75 и наоборот.
