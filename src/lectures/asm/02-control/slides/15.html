02 / разбор · while

while: проверка перед телом.

1 · На C
while (i < limit) {
    i++;
}

EAX = i · EBX = limit · signed32

2 · На NASM
check: cmp eax, ebx
jge done
inc eax
jmp check
done:

jge done: i ≥ limit → выход. После тела jmp check возвращается к CMP.

Пройти три блока: EAX = i, EBX = limit. Метка check — адрес проверки; без неё jmp некуда вернуться.

Спросить: куда ведёт jmp check? Ответ: на cmp по метке check — к проверке, а не к телу. Если возвращаться на inc, проверка была бы пропущена.

Спросить: сколько раз выполнится тело при i = limit сразу? Ответ: ни разу — сначала проверка, выход сразу при ложном условии.

Далее: слайд 16 проходит цикл пошагово с выбором EAX/EBX 0…5, историей счётчика и байтами 39 D8, 7D 04, FF C0, EB F8.
