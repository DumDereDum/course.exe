02 / инструкция к примерам

Ручная сборка: Windows и macOS.

VS Code: открыть весь репозиторий, Terminal → New Terminal.

Windows: PowerShell; Docker Desktop с WSL 2 и Linux-контейнерами.

macOS: Zsh/Bash. Запустить Docker Desktop.

В рабочей папке: max.asm, abs.asm, sum.asm, for.asm.

1 / Windows · PowerShell
Set-Location .\examples\asm
Get-ChildItem
macOS · терминал
cd examples/asm
ls
2 / На компьютере · из examples/asm
docker run --name asm-examples --platform linux/amd64 -it --mount "type=bind,source=${PWD},target=/work" -w /work debian:bookworm-slim bash

${PWD} — уже папка исходников, без дополнительного пути.

После входа · внутри Linux
pwd
ls

Ожидаем /work и четыре .asm. Повторный вход с компьютера: docker start -ai asm-examples.

3 / Инструменты и ручная сборка
apt-get update
apt-get install -y nasm binutils
mkdir -p build
nasm -f elf64 sum.asm -o build/sum.o
ld -o build/sum build/sum.o

nasm создаёт .o, ld — исполняемый ELF. Сначала сохранить файл.

Ручной запуск и проверка
./build/sum
echo "$?"

Ожидаем 10. Для max, abs и for повторить NASM, ld и запуск со своим именем.

4 / Дизассемблировать ELF
objdump -d -M intel build/sum

-d — кодовые секции; -M intel — Intel-синтаксис.

Байты цикла из sum.asm
39 D8    cmp eax, ebx
7F 06    jg done
EB F6    jmp check

Найти сравнение, выход и обратный переход.

5 / Заголовки и байты ELF
readelf -h build/sum
readelf -S build/sum
od -Ax -tx1 -N64 build/sum

7F 45 4C 46 — сигнатура ELF; od показывает файловые смещения.

Извлечь и разобрать код .text
objdump -s -j .text build/sum
objcopy -O binary -j .text \
  build/sum build/sum.text.bin
ndisasm -b64 build/sum.text.bin

Все эти команды — внутри Linux на Windows и macOS.

Перед Docker перейти в examples/asm; внутри /work команды Linux одинаковы на обеих ОС. Студенты вручную вызывают NASM, ld, программу и echo. Подробности — README. Windows и браузер не проверены.
