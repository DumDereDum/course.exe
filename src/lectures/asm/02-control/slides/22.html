Папка в репозитории: examples/asm/

Результат — код завершения, без печати. echo "$?" сразу после запуска: младшие 8 бит.

Четыре полных примера: max=7, abs=7, sum=10, for=6. Студенты открывают весь репозиторий в VS Code и работают в examples/asm. Следующий слайд — инструкция перехода в examples/asm и ручного запуска на Windows/macOS. Сборка: исходник → объектный файл → исполняемый ELF. Завершение Linux x86-64: mov edi, результат; mov eax, 60; syscall. Сохранить результат до перезаписи EAX. Ненулевой код в этих четырёх примерах передаёт число; stdout пуст. Пятый пример text.asm разобран на слайдах 26–28 и включён в общий архив: он печатает строку и при успехе возвращает 0.

abs: CMP с нулём и JGE обходят NEG для неотрицательного числа. NEG вычисляет 0 − EAX и меняет арифметические флаги. Для −2147483648 положительный модуль не помещается в signed32: NEG оставляет 80000000 и выставляет OF=1. В учебных запусках ограничиваем |VALUE|≤255; это не реализация модуля для всего signed32.
