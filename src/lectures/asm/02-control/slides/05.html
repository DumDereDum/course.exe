02 / каталог условных переходов

После cmp a, b: выбор условия.

Со знаком · смысл · флаги · код
jl   a < b   SF ≠ OF         7C
jle  a ≤ b   ZF=1 или SF≠OF  7E
jg   a > b   ZF=0 и SF=OF    7F
jge  a ≥ b   SF = OF         7D
Без знака · смысл · флаги · код
jb   a < b   CF = 1          72
jbe  a ≤ b   CF=1 или ZF=1   76
ja   a > b   CF=0 и ZF=0     77
jae  a ≥ b   CF = 0          73
Равенство · обе трактовки

je / jz: a = b · ZF = 1 · 74  ·  jne / jnz: a ≠ b · ZF = 0 · 75

7x — код короткого перехода. Signed или unsigned выбираем по типу данных.

Сказать: после cmp eax, ebx каждая строка читается одинаково: первая колонка — смысл, далее условие по флагам, далее байт. Таблица сравнивает EAX с EBX; перестановка операндов меняет смысл.

Правило выбора: знаковые счётчики и значения с возможным минусом — jl/jle/jg/jge. Адреса, размеры, биты — jb/jbe/ja/jae. Равенство проверяют je/jne всегда.

Спросить: почему для равенства не нужна трактовка? Ответ: нулевая разность — это одно и то же битовое состояние ZF=1 при любом смысле чисел.

Синонимы: je/jz и jne/jnz — одинаковые кодировки, дизассемблер может писать jz/jnz. jc — то же, что jb (проверка CF=1).

Граница: условия по флагам даны в общепринятом виде (Intel SDM, Jcc). Машинный код не разбираем: короткие переходы 7x + смещение, длинные формы существуют. Дальше подробно разбираем используемые переходы: je/jne — слайд 06, test и jz — слайд 08, jl/jb — слайд 11.
