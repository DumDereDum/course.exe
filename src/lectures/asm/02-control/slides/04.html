02 / условные переходы

je и jne проверяют ZF
и выбирают следующий адрес.

Начальные значения · 0…99

Мысль: je проверяет ZF=1, jne — ZF=0. Сам переход операнды не сравнивает и флаги не меняет. CMP устанавливает ZF по равенству выбранных EAX и EBX.

Показ: сначала оставить 7 и 7, je. Выполнить cmp: ZF=1; затем je: RIP уходит на yes. Mov ecx, 1 завершает маршрут с ECX=1. Изменить EBX на 3: показ возвращается к началу. CMP даёт ZF=0; je не переходит, mov ecx, 0 записывает 0, jmp done пропускает вторую ветку.

JNE: выбрать jne с теми же числами. Переход теперь срабатывает при различии. Метка yes обозначает выполнение условия выбранного перехода, а не обязательно равенство. ECX=1 означает переход сработал, ECX=0 — пропущен.

Байты: изменение je/jne заменяет 74 на 75. Смещение 07 одинаково: отсчитывается от 0x401004 до yes=0x40100B. EB 05 пропускает пятибайтовую mov ecx, 1. Hover и Tab показывают роль байта и таблицу HEX/BIN. JE/JZ и JNE/JNZ — одинаковые кодировки; дизассемблер может использовать JZ/JNZ.

Управление: числа и команда выбираются сверху; любое изменение возвращает показ к началу. Пробел — инструкция, Shift + пробел — назад, R — начало с выбранными числами. В полях ввод не перехватывается. В конце остановка. Состояние сохраняется при листании. Время: 6–8 минут.

Граница: отдельная модель конкретного фрагмента, не эмулятор x86. Начальные EAX/EBX задаются непосредственно; MOV для их загрузки не показаны. Для читаемости выбор ограничен целыми 0…99. ZF до CMP и ECX до MOV неизвестны. Показан только ZF; остальные флаги опущены. Адреса условные, done — адрес продолжения, его инструкция не задана. Кодировки и смещения проверены NASM для обеих команд.
