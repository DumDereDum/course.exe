02 / разбор · test и jz

test: AND без записи результата.

1 · На C
if (x == 0) { … }
if (x % 2 == 0) { … }

EAX = x · zero и even — ветки проверок

2 · На NASM
; Два отдельных фрагмента
test eax, eax
jz zero

test eax, 1
jz even

Результат AND равен 0 → ZF = 1 → jz срабатывает. Маска 1 проверяет младший бит; ноль тоже чётный.

Пройти три блока: на C — проверка нуля и чётности; инструкции — test вместо cmp; логика — AND без записи, ZF по нулевому результату.

Спросить: изменится ли EAX после test? Ответ: нет, оба операнда сохраняются; меняются только флаги.

Спросить: почему jz, а не je? Ответ: синонимы: оба проверяют ZF=1, одна кодировка. Дизассемблер может показывать любое имя.
