02 / выбор перехода

Как выбрать условный переход.

cmp eax, ebx — сравниваем EAX с EBX.

Условие        Со знаком · signed       Без знака · unsigned
EAX < EBX      jl                       jb



 
Условие        Со знаком · signed       Без знака · unsigned
EAX < EBX      jl                       jb
EAX ≤ EBX      jle                      jbe
EAX > EBX      jg                       ja
EAX ≥ EBX      jge                      jae
 
Условие        Со знаком · signed       Без знака · unsigned
EAX < EBX      jl                       jb
EAX ≤ EBX      jle                      jbe
EAX > EBX      jg                       ja
EAX ≥ EBX      jge                      jae
Для обоих:     je — равны;              jne — не равны

Сначала смысл чисел, затем команда перехода.

Сказать: CMP EAX,EBX выставляет флаги как EAX−EBX, сохраняя операнды. Таблица сравнивает EAX с EBX; перестановка операндов меняет смысл. Между CMP и переходом сохраняем нужные флаги.

Показ: JL/JB → остальные сравнения → JE/JNE. Less/greater — со знаком, below/above — без знака; E добавляет equal. Напомнить FFFFFFFF и 1. Угадывание не требуется.

Объяснить: в регистре нет типа. Равенство не зависит от трактовки. JE/JZ и JNE/JNZ — синонимы. Наведение на команды раскрывает формулы флагов стандартной браузерной подписью.

Управление: пробел, Shift + пробел, R. Три кадра, около 5 минут. Далее — максимум двух чисел через IF/ELSE.

Источник: Intel SDM, Vol. 1, Table 7-4: https://cdrdv2-public.intel.com/843820/325462-sdm-vol-1-2abcd-3abcd-4-1.pdf.
