# Лекция 1 — введение в ISA и первые команды

Аудитория: студенты, знакомые с переменными и простыми функциями на C.
Цель: связать исходный код, инструкции, регистры и машинные байты, затем научиться собирать и наблюдать простые программы.
Платформа: x86-64, Linux, NASM; Intel-синтаксис.
Формат: сопровождение живого объяснения преподавателя, не самостоятельный учебник.
Текущий объём: 26 слайдов на 90 минут. Лекция завершается готовой программой Hello и разбором сборки и запуска. Последний слайд даёт инструкцию запуска готового Debian x86-64 через Docker и установки NASM/binutils через apt-get. Реальный запуск среды пока не проверялся.

Сквозной пример: `long calc(long a, long b, long c) { return (a + b) - c; }`.
Учебная asm-реализация демонстрирует вычисление; она не обязана совпадать с выводом оптимизирующего компилятора.
