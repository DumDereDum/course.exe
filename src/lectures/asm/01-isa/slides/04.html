ISA · Instruction Set Architecture

CISC и RISC — два подхода
к устройству набора команд.

CISC · x86-64

Complex Instruction Set Computer

Компьютер со сложным набором команд.

; sum += *ptr
add rax, [rdi]

Одна инструкция читает память и выполняет сложение.

RISC · ARM64 и RISC-V

Reduced Instruction Set Computer

Компьютер с сокращённым набором команд.

; ARM64
ldr x2, [x0]
add x1, x1, x2
; RISC-V
ld  t0, 0(a0)
add a1, a1, t0

Сначала загрузка из памяти, затем вычисление в регистрах.

Сказать: CISC и RISC описывают стиль ISA. x86-64 допускает инструкции с операндами в памяти. ARM64 и RISC-V следуют load/store-подходу: арифметика работает с регистрами, а память обслуживают отдельные команды.

Уточнить: слово Reduced исторически означает упрощённые и регулярные форматы, а не обязательно маленький современный набор команд.

Спросить: можно ли по одной строке x86 и двум строкам ARM заключить, что x86 быстрее? Ответ: нет. Важны микроархитектура, кэш, память, компилятор и конкретная программа.

Граница примера: регистры в трёх фрагментах выбраны по-разному, но выражают одну операцию: прибавить к sum значение по адресу ptr.
