Скачать hello.asmГотовый исходник для практики · NASM / Linux x86-64

Показ: четыре состояния: полный исходник, NASM, ld, запуск. Пробел — следующий этап, Shift + пробел — предыдущий, R — исходник. Верхняя цепочка сохраняется и подсвечивает текущий результат.

Исходник: две колонки продолжают один файл, это видно по номерам строк. Начало и вывод в строках 1–8, exit и данные — в строках 9–13. Первый syscall возвращается после write; поэтому следом стоит exit(0). Файл по ссылке и встроенный источник для скачивания содержат тот же исходник. Кнопка скачивает hello.asm через Blob и сохраняет открытый слайд; папку выбирает браузер.

Сборка: в каталоге с hello.asm выполнить nasm -f elf64 hello.asm -o hello.o, затем ld -o hello hello.o. NASM создаёт объектный файл; GNU ld создаёт исполняемый файл, размещая секции и разрешая ссылку на message. Пример использует абсолютный адрес метки и обычный исполняемый файл без PIE.

Запуск: ./hello запускает файл из текущего каталога. После запуска выполнить echo $? сразу, чтобы увидеть код именно этой программы. Здесь 0 передан в RDI для exit; это другой результат, чем 6 в RAX после write.

Спросить: зачем нужен второй syscall? Ответ: первый выводит строку и возвращает управление, второй завершает процесс.

Граница: терминал показывает сохранённый ожидаемый пример, команды не исполняются в браузере. Среда — Linux x86-64 с NASM и GNU ld; это не команды для непосредственного запуска программы в macOS или Windows. Установочная практика и единая учебная среда готовятся отдельно.
