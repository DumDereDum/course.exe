Что это

Текст, который написал программист. Типы, переменные и выражения ещё сохранены.

Пример содержимого
long calc(long a, long b, long c) {
    return (a + b) - c;
}

Переменные стали регистрами, а выражение — последовательностью инструкций x86-64.

Что изменилось

Код и данные получили адреса. Файл содержит всё необходимое загрузчику ОС для запуска.

Фрагмент дизассемблера
0000000000401000 <calc>:
401000: 48 89 f8  mov rax,rdi
401003: 48 01 f0  add rax,rsi
401006: 48 29 d0  sub rax,rdx

Показ: пробелом пройти четыре состояния. На каждом шаге сначала назвать преобразование, затем прочитать пример справа. Shift + пробел — назад, R — сначала.

Спросить: на каком этапе инструкции впервые становятся байтами? Ответ: при создании объектного файла ассемблером.

Границы модели: промежуточный .s не всегда сохраняется на диск. Адрес 0x401000 приведён как учебный пример и может отличаться в реальной сборке.
