1 · Установить Docker

Установите и запустите Docker Desktop. На Windows используйте Linux-контейнеры.

2 · Скачать файлы

Положите оба файла в отдельную папку asm-practice. В Dockerfile уже описана установка NASM и компоновщика.

Скачать DockerfileСкачать hello.asm

3 · Открыть терминал

Откройте терминал в папке asm-practice: PowerShell на Windows, Terminal на Mac или терминал Linux.

Далее: нажмите ⧉, вставьте команду в терминал и нажмите Enter.

1 / Собрать образ · терминал компьютера · папка asm-practice
docker build --platform linux/amd64 -t asm-course .

Docker скачает Linux x86-64 и установит NASM и GNU ld.

Готовый образ asm-course сохраняется на компьютере. Этот шаг выполняется один раз.

2 / Открыть среду · терминал компьютера · та же папка
docker run --rm -it --platform linux/amd64 -v "${PWD}:/work" -w /work asm-course

Папка asm-practice доступна в Linux как /work.

Программы собираются и запускаются внутри Linux. Исходники и результаты сборки остаются в вашей папке.

3 / Собрать программу · теперь в терминале Linux
nasm -f elf64 hello.asm -o hello.o
ld -o hello hello.o

Теперь введите сами: ./hello

Выход — exit. На следующем занятии повторите команду открытия среды.

⧉ копирует команды, студент вставляет их в терминал и нажимает Enter. На Windows нужен PowerShell. ./hello вводится вручную.

После exit контейнер удаляется, образ и файлы остаются. Повторный вход — docker run. На Linux ARM нужна эмуляция. Реальная сборка образа здесь не проверялась.
