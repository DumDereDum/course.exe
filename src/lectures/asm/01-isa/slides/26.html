1 · Установить Docker

Установите и запустите Docker Desktop. На Windows используйте Linux-контейнеры.

Mac ↗Windows ↗Linux ↗

2 · Скачать пример

Сохраните файл в папку, где будете работать.

Скачать hello.asm

3 · Открыть терминал

Откройте терминал в папке с файлом: PowerShell на Windows или терминал macOS/Linux.

Нажмите ⧉, вставьте команду в терминал и нажмите Enter.

1 / Скачать образ и открыть Linux · терминал компьютера
docker run --name asm-course --platform linux/amd64 -it -v "${PWD}:/work" -w /work debian:bookworm-slim bash

Ваша папка доступна в Linux как /work.

Для первой загрузки нужен интернет. Команда одинаковая для PowerShell и терминалов macOS/Linux.

2 / Установить инструменты · внутри Linux
apt-get update
apt-get install -y nasm binutils

nasm — ассемблер. binutils содержит компоновщик ld.

Дождитесь окончания установки. Инструменты сохранятся в контейнере asm-course.

3 / Собрать программу · внутри Linux
nasm -f elf64 hello.asm -o hello.o
ld -o hello hello.o

Теперь введите сами: ./hello

Выход — exit. В следующий раз откройте эту среду на компьютере:

docker start -ai asm-course

Кнопки копируют команды; студент вставляет их в терминал и нажимает Enter. docker run выполняется один раз в папке с hello.asm. apt-get, NASM и ld — внутри Linux. ./hello вводится вручную.

Контейнер сохраняется после exit вместе с инструментами, файлы остаются в подключённой папке. Повторный вход — docker start. На Linux ARM нужна настроенная эмуляция. Реальное выполнение здесь не проверялось.
