# Работа с библиотекой лекций

Для добавления или изменения слайда сначала прочитать `SLIDE_GUIDE.md`.
Затем — `brief.md` нужной лекции и один шаблон из `templates/slides/`.
Не загружать весь репозиторий, CSS/JS и собранные лекции без необходимости.

Править источники в `src/lectures/`, затем запустить сборку.
`index.html` и `lectures/` генерируются и хранятся в репозитории.
Главная: простой терминал на всё окно, темы assembler и common (в common папка git).
Не добавлять разделение по курсам, большие иллюстрации и боковые панели.
Слайды: спокойные, читаемые, 16:9. Мастерская _kit доступна напрямую, вне меню.
Просмотр должен работать из file:// без установки зависимостей.

Для изменения общей архитектуры прочитать `SPEC.md`; это не нужно автору слайда.
Проверки: `python3 build.py --check`, `python3 -m unittest discover -s tests`.
После изменения интерфейса проверить браузером целевой сценарий и компоновку.
Не добавлять зависимости и не перерабатывать движок ради одного слайда.
