01 / внешняя демонстрация

Сначала предскажем.
Потом проверим.

Сохранённый вход
int answer(void) {
    return 6 * 7;
}
Ожидаемое наблюдение

Компилятор может вычислить константное выражение до запуска программы.

mov eax, 42
ret
Открыть Compiler Explorer ↗

Сохранённая иллюстрация x86-64. Для точного повтора закрепите версию компилятора и ссылку Share.

Цель: увидеть вычисление константного выражения.

До занятия: в Compiler Explorer выбрать C, x86-64 GCC, -O2 -masm=intel. Проверить код, записать версию и заменить ссылку на подготовленную Share-ссылку.

Показ: спросить, нужна ли инструкция умножения, затем сравнить код и результат. Без сети: разобрать сохранённую иллюстрацию. Ничего не писать с нуля.

01 / схема из отдельного файла

Сложность скрывается
за интерфейсом.

Каждый уровень даёт следующему понятный способ взаимодействия.

Попросить назвать пример операции: чтение файла. Провести её через три уровня. Для новой темы заменить картинку и описание alt.

01 / отдельная интерактивная сцена

Демонстрация
внутри лекции.

Подготовленный конвейер: сборка → тесты → публикация.

Демо загружается по кнопке. Открыть отдельно ↗. Резервный разбор: исходники → сборка → тесты → артефакт.

Цель: показать зависимость шагов. Встроенный пример работает офлайн и не запускает настоящую сборку.

Показ: нажать «Следующий этап» три раза, обсудить появление результата после тестов. Сбросить.

Для Docker-демо заменить data-src и ссылку на проверенный адрес локального сервиса, записать команду запуска и ожидаемый результат здесь. Внешний сайт может запрещать встраивание; тогда открыть отдельно. После работы с iframe кликнуть вне него для клавиш слайдов.
