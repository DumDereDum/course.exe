# Registers — небольшой учебный шагатель

Готовый файл: `templates/slides/registers.html`.
Обёртка `.widget[data-widget="registers"]`; внутри `.split` с двумя частями:
`<pre class="code program" data-program data-regs="rax,rbx,rcx,rdx">` и
`<div class="registers" data-registers></div>`. Панель, пояснения и кнопки строятся сами.

Каждая команда — отдельный непосредственный `<span>` в pre. Не вставлять комментарии,
номера строк и вложенную разметку. Переносы между span несущественны.
`data-explain` — объяснение результата именно этой команды, показывается после шага.

| data-do | Результат |
|---|---|
| `{"set":{"rax":"10"}}` | записать число |
| `{"set":{"rax":"rbx"}}` | скопировать регистр |
| `{"add":{"rax":"rbx"}}` | прибавить регистр; допустим и числовой операнд |
| `{"inc":"rax"}` | увеличить на 1 |
| `{"xor":{"rax":"rbx"}}` | побитовое XOR двух значений |
| `{}` или отсутствие data-do | подготовленный шаг без изменения состояния |

Числа передавать **строками**: `"10"`, `"-1"`, `"0xff"`, чтобы не терять точность.
Все регистры первоначально 0. Арифметика — беззнаковые 64 бита с переполнением.
`add`, `inc`, `xor` обновляют только ZF; `set` оставляет его прежним.
Явный `"zf":0` или `"zf":1` допустим для специального подготовленного шага.
Подсвечиваются изменившиеся регистры; счётчик — число шагов, **не настоящий RIP**.

Это **не эмулятор x86**. Нет переходов, памяти, стека, подрегистров и остальных флагов.
Не писать `eax`, если объясняется обнуление верхней половины rax: движок этого не моделирует.
Для таких тем взять sequence и явно подготовить правильные состояния.

До 6 команд и 4 регистров. Назад восстанавливает точное предыдущее состояние, сброс — нули.
После последней команды остановка. Стрелки никогда не выполняют инструкции.
