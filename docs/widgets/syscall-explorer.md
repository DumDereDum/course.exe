# Syscall explorer — карта Linux x86-64

Шаблон: `templates/slides/syscall-explorer.html`.
Обёртка `.widget[data-widget="syscall-explorer"]` содержит один пустой `<div data-syscall-explorer></div>`.
Компонент строит фиксированный учебный каталог из 20 системных вызовов Linux x86-64: файлы,
память, процессы и сеть. Для каждого показывает номер в RAX, сигнатуру, регистры аргументов,
результат и короткое назначение. Числа относятся только к Linux x86-64.

Клик выбирает вызов. Пробел / Следующий проходит каталог, Shift + пробел / Назад возвращает
предыдущий выбор, R / Сброс выбирает write. Каталог справочный: он не выполняет системные вызовы.
