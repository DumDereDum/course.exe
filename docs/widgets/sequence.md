# Sequence — подготовленные состояния

Начните с `templates/slides/sequence.html`. Никакого JavaScript внутри слайда.

Контракт: `.widget[data-widget="sequence"]` → `.sequence-viewport` →
2–5 элементов `.sequence-frame[data-frame][data-caption="Пояснение шага"]`.
Внутри каждого кадра — обычные компоненты: схема flow, код code, колонки, SVG, текст.
Кнопки, подпись и счётчик добавляются автоматически. Не добавляйте их вручную.

Первый кадр — исходное состояние; каждый следующий меняет только обсуждаемую часть.
Все кадры занимают общую область высотой самого большого кадра: подпись не прыгает.
Не скрывайте информацию разным кеглем. Классы `current`/`inert` выставляет движок.

Управление: пробел / Далее; Shift + пробел / Назад; R / Сброс.
На последнем кадре выполнение останавливается. Переход к другому слайду — стрелка.
Состояние сохраняется при листании, но сбрасывается при перезагрузке страницы.

Терминальное демо: в каждом кадре подготовленный `<pre class="code">` с командой
и её ожидаемым выводом. Подписать «сохранённый пример», если команды не выполняются.
Сложные схемы храните отдельными SVG и вставляйте через `@ASSETS@`.
