# Endian — порядок четырёх или восьми байтов

Шаблон: `templates/slides/endian.html`.
`.widget[data-widget="endian"][data-value="0x12345678"]` задаёт беззнаковое 32-битное число.
Для восьми байтов добавить `data-width="64"` и, например, `data-value="0x1122334455667788"`.
Без `data-width` сохраняется 32-битный режим. Допустимы только ширины 32 и 64.
Внутри обязательны `data-memory`, `data-readout`, `data-endian-caption` и две кнопки
`data-mode="le"` / `data-mode="be"`. Тексты/байты заполняет движок.

Начало — little-endian. Пробел и Shift + пробел переключают режим, R возвращает little-endian.
Один и тот же операнд заново раскладывается в память. Значение readout остаётся тем же.
Это не переинтерпретация неизменных байтов. Не смешивать эти два сценария в объяснении.
Адреса +0…+3 или +0…+7 растут слева направо. Значение должно помещаться в выбранную разрядность.
