# Command lab — подготовленные примеры инструкций

Шаблон: `templates/slides/command-lab.html`.
Обёртка `.widget[data-widget="command-lab"]` задаёт список отображаемых регистров в `data-regs`.
Внутри нужны `.command-lab-examples[data-command-examples]` и `.command-lab-state[data-command-state]`.

Каждый из 2–5 непосредственных примеров — кнопка `[data-command]`.
`data-before` и `data-after` содержат JSON-объекты: имена 64-битных регистров и беззнаковые строки decimal/hex.
`data-after` перечисляет только изменившиеся значения. Виджет показывает подготовленные состояния и не исполняет текст команды.
`data-prompt` — вопрос до выполнения, `data-explain` — объяснение после.
`data-flags-after` может содержать ZF/CF/SF/OF со строками `0`, `1` или `?`.
`data-bits="rax,rbx"` добавляет младшие восемь бит выбранных регистров.

Клик по примеру загружает состояние «до». Выполнить или пробел показывает состояние «после».
Следующий пробел выбирает следующий пример. Shift + пробел / Назад отменяет выбор или выполнение, R сбрасывает первый пример.
Изменившиеся регистры и заданные флаги подсвечиваются. Значения регистров показываются как 64-битный hex и unsigned decimal.
Наведение или клавиатурный фокус на ZF/CF/SF/OF показывает расшифровку флага и смысл текущего значения.
