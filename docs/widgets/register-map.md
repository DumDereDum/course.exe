# Register map — регистры и запись в их части

Шаблон: `templates/slides/register-map.html`.
Обёртка `.widget[data-widget="register-map"]` содержит один пустой `<div data-register-map></div>`.
Не вставлять внутрь собственную карту: компонент создаёт её вместе с управлением.
`data-initial` — необязательное беззнаковое 64-битное число, decimal или hex; по умолчанию `0x1122334455667788`.

Карта содержит 16 регистров общего назначения, RIP и RFLAGS. Выбор регистра открывает его роль,
байты от старших битов к младшим и имена доступных частей. Выбор части подсвечивает соответствующие байты.
Кнопка Выполнить делает подготовленную mov: AA для 8 бит, BBBB для 16, CCCCDDDD для 32,
FFEEDDCCBBAA0099 для 64. При записи 32 бит верхняя половина обнуляется; запись 8/16 сохраняет остальные биты.
Каждый регистр хранит своё значение. Изменённые байты выделяются, обнулённая половина имеет пунктирную границу.

Пробел / Следующая запись: младшие 8 → 16 → 32 → 64, затем остановка.
Shift + пробел / Назад: отмена предыдущего действия, включая выбор регистра и части.
R / Сброс: исходные значения, RAX и выбор всех 64 бит.
Состояние сохраняется при листании, перезагрузка его сбрасывает.

RIP и RFLAGS не принимают mov; у RFLAGS доступны пояснения CF, ZF, SF, DF, OF.
Учебная модель не исполняет произвольный код и не моделирует память, стек, изменения флагов или режимы процессора.
Не трактовать порядок байтов на схеме как порядок байтов в памяти.
