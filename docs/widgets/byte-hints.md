# Подписи машинных байтов

Это дополнение к SVG внутри sequence, а не второй основной виджет.
Образец: `templates/slides/byte-hints.html`.

1. Во внешнем SVG обернуть каждый байт (две hex-цифры) в группу:

```xml
<g data-byte="48" data-byte-hint="Префикс REX.W: операция над 64-битными регистрами.">
  <rect class="byte-hit" x="240" y="119" width="40" height="34" rx="4" fill="transparent"/>
  <text x="245" y="146" font-size="25">48</text>
</g>
```

2. В слайде указать `<img class="diagram" data-byte-hints src="@ASSETS@/diagrams/example.svg" alt="Описание схемы">`.
3. Собрать лекцию. Сборщик вставит размеченный SVG в HTML, переназовёт ID и подключит маленький компонент подписей только в этой лекции.

Наведение, фокус через Tab и клик показывают подпись внутри слайда. Уход мыши, потеря фокуса, Esc, шаг, сброс и смена слайда её скрывают. Пробел и стрелки сохраняют управление лекцией. Не использовать native title на группах байтов, иначе появится вторая браузерная подсказка.

Для самостоятельной сцены без sequence перед обновлением состояния отправить событие byte-hints-reset на .byte-diagram. Это закрывает подпись старого байта; conditional-jump делает это при каждом шаге и смене данных.

Подпись начинается с таблицы HEX/BIN: две hex-цифры в отдельных колонках, под каждой — четыре бита с ведущими нулями. Например, B8 показывается как B | 8 и 1011 | 1000. Это два полубайта одного байта, а не два отдельных байта. Таблица формируется автоматически из data-byte; описание роли байта идёт под ней.

Верхний SVG title/desc описывает схему; byte-hint объясняет конкретный байт, а не обязательно целую команду. Константы могут занимать несколько байтов: указать номер байта и значение всей константы. Обычные картинки остаются обычными img. Просмотр автономен через file://: fetch, внешние шрифты и зависимости не нужны.
