# Внешний показ, копирование и встраивание

Шаблоны: `external.html`, `embed.html`. Базовые слайды не требуют сети.

## Ссылка на подготовленный пример

Обычная ссылка с `target="_blank" rel="noopener"` открывается отдельно, лекция остаётся на месте.
В сценарии `.notes`: цель → среда и версия → действия → ожидаемое наблюдение → резерв.
В Compiler Explorer заранее выбрать язык/компилятор/опции, проверить код и сохранить URL через Share.
URL главной страницы — только заготовка, не готовый показ. Не придумывать Share-ссылки.
Оставлять на слайде локальный код и результат, чтобы тот же разбор был возможен без сети.

Копирование: `button[data-copy=".copy-source"]` ищет `.copy-source` **только в своём слайде**.
Рядом с кнопкой разместить `<span class="copy-status" aria-live="polite"></span>`.
Если Clipboard API недоступен из file://, используется резервное копирование
выделенного текста через браузер. Если оно тоже запрещено, код остаётся выделенным
для Ctrl/Cmd+C. Статус «Скопировано» появляется только после успешного копирования.
Для длинных команд используйте `code command-wrap`: переносы визуальные и не добавляют
новые строки в скопированную команду. Это позволяет одинаковой однострочной команде
работать в PowerShell и терминалах macOS/Linux.

## Скачивание текстового файла

Для работы из file:// добавить к ссылке `download="hello.asm"`
и `data-download="#hello-download-source"`. В том же слайде разместить
`<template id="hello-download-source">точное содержимое файла</template>`.
Содержимое начинается сразу после открывающего тега, без добавочного переноса;
сохраняйте переводы строк и экранируйте HTML-символы. Оно должно совпадать с файлом по href.
resources.js по явному клику создаёт Blob и запускает скачивание без загрузки
локального файла через fetch. href остаётся резервной прямой ссылкой.
Имя берётся из download; папка назначения и запрос выбора папки управляются браузером.

## Отдельная интерактивная сцена

```html
<div class="embed-box" data-embed
     data-src="@ASSETS@/demos/pipeline.html" data-title="Учебная модель конвейера">
  <p>Сборка → тесты → артефакт.</p>
  <button class="btn primary" data-load-embed>Открыть пример</button>
</div>
```

Скрипт создаёт iframe **только после нажатия**. Кнопка «Закрыть демо» выгружает его,
поэтому повторное открытие начинает сцену заново. Добавить рядом обычную ссылку «Открыть отдельно»
и резервную схему/код: некоторые сайты запрещают iframe, а локальный сервис может быть не запущен.
Фокус внутри iframe принадлежит демо; клик вне него возвращает управление клавишами лекции.

Для Docker заменить data-src и ссылку на проверенный localhost URL. В заметках зафиксировать
точную команду запуска, порт, версию/образ и шаги остановки/сброса. Не запускать Docker автоматически
при открытии слайда. Сервер и контейнер не входят в базовую сборку.

Локальный пример `assets/demos/pipeline.html` — автономная учебная модель, настоящих команд не выполняет.
Новый сложный интерактив хранить отдельным небольшим HTML/JS, с собственным описанием интерфейса.
Не встраивать неизвестные страницы; слайд не изолирует доверенное демо как песочница безопасности.
